# 技と必殺技の仕様(2026-10-28 ユーザー確定)

技は「タイプの技6つ+属性の技4つ」から覚え、バトルで使う4つを選んでセットする。必殺技はSPでだけ強くなる。

## ルール
- 4枠:覚えた技から4つを選んでセット(ステータス画面で入れ替え)。セットの外に、MP0の「通常攻撃」(威力1.0)をいつでも使える
- 相性:水>火>風>土>雷>水。光と闇はお互いに強い。強い相手に1.5倍、弱い相手に0.7倍。技の属性と、受ける側のキャラの属性で決まる。敵の技にも効く
- 種類:物理(攻撃力)・魔法(魔攻力)・両方(攻撃と魔攻の平均)・回復・補助・弱体・防御
- 補助・弱体:3ターン続く。同じ効果は重ならず、ターン数だけ戻る。違う効果は重なる
- MPは自然には回復しない:毎ターンの+1と、ぼうぎょの+2はなくす。回復は、MP回復アイテム・たき火・泉と祠。ダンジョンではバトルをまたいで持ち越す。修行バトルは毎回満タンから
- ぼうぎょ:そのターン受けるダメージ半分(MPは回復しない)
- MPのトレーニング「精神統一」を足して、最大MPを上げる(なくす「必殺技練習」の代わり)
- 敵:敵も同じ技の一覧から、タイプと属性で技を持つ

| 技の強さ | 威力 | MP |
| --- | --- | --- |
| 通常攻撃 | 1.0 | 0 |
| 弱 | 1.3〜1.4 | 3 |
| 中 | 1.8〜2.2 | 6〜8 |
| 強 | 2.4〜2.8 | 10〜14 |
| 最強 | 3.0〜3.2 | 18〜20 |
| 補助・弱体・防御 | — | 5〜10 |
| 回復 | — | 6〜16 |

## 必殺技
成長体で解放。SPは能力には振れず、必殺技のレベル(1〜10)にだけ使う。レベルはその子だけ(寿命で1に戻る)。名前は今のタイプごとのまま。

| レベル | 威力 | ゲージ(当てる回数) | 次のレベルに必要なSP |
| --- | --- | --- | --- |
| 1〜3 | ×2.5〜×2.7 | 5回 | 35・65・100 |
| 4〜6 | ×2.8〜×3.0 | 4回 | 135・165・200 |
| 7〜9 | ×3.1〜×3.3 | 3回 | 235・265・300 |
| 10 | ×3.5 | 3回 | 最大 |

- 威力はレベルごとに+0.1(10で+0.2)。レベル10までの合計は1,500SP(約15万歩)
- レベル5で属性の追加効果が付き、レベル10で強くなる
- 今の「必殺威力」の能力と「必殺技練習」はなくす

| 属性 | レベル5の追加効果 | レベル10 |
| --- | --- | --- |
| 火 | やけど:3ターン、毎ターン敵の最大HPの5% | 8% |
| 水 | 与えたダメージの20%、HP回復 | 35% |
| 風 | 3ターン、自分の素早さ+50% | +80% |
| 雷 | まひ:30%で敵が1回休み | 50% |
| 土 | 3ターン、敵の防御-25% | -40% |
| 光 | 自分の弱体を消してHP10%回復 | 20% |
| 闇 | 3ターン、敵の攻撃-25% | -40% |

## ボスの技(2026-11-03 ユーザー確定)
ダンジョンのボスは、エリアの属性ごとの技5つ(①〜⑤、弱い順)と、属性の必殺技を使う。補助技(ためる・強化・耐性の見せ場)はこれまで通り。

### 使う技の増え方(1エリア=5階層)
| エリアの何階層目 | 使う技 |
| --- | --- |
| 1 | ①② +属性の必殺技 |
| 2 | ①〜③ +必殺技 |
| 3 | ①〜④ +必殺技 |
| 4 | ①〜⑤ +必殺技 |
| 5(守護者) | ①〜⑤ +必殺技+守護者の必殺技 |

- 属性の必殺技:今の「ためる大技」と置き換える。力をためた次のターンに撃ち、強さは今のためる大技と同じ。全部のボスが使う(普通のボスの見せ場が「強化」「耐性」でも、ためて必殺技を撃つ)
- 守護者の必殺技:本気モード(HPが半分を切ったとき)に1回だけ撃つ。受ける側の最大HPの約55%(ハオウリュウだけ約60%)+属性の効果
- 星・闘志・王者のエリア(属性なし):普通のボスは、ボス自身の属性の技表を使う。増え方は同じ
- 属性なしの守護者3体(2026-11-03 ユーザー確定):いくつもの属性を持つ。ホシワタリ=水・風・光、トウキオウ=火・土・雷・闇、ハオウリュウ=全7属性
  - ①〜③は使わない。攻撃技は④⑤で、毎回、持っている属性から1つ選んで、その属性の④か⑤を撃つ。補助(ためる・強化・耐性の見せ場)、属性の必殺技、守護者の必殺技は、ほかの守護者と同じように使う
  - 属性の必殺技も、ためるたびに持っている属性からランダム
  - 体は属性なし(こちらの技は等倍)。「同じ属性に強い」は、直前に使った技の属性にだけ効く(例:火の技を使ったあとは火が効かない)
  - 守護者の必殺技の効果は、持っている属性の効果から1つランダム
  - 封魔の波動(ふうまのはどう):こちらにかかっている補助(能力アップ・バリアシールド・カウンターアーム・フルチャージ・毎ターン回復)を全部消す。ダメージなし。こちらに補助がかかっているときだけ、30%で使う(手番を使う。2ターン続けては使わない)。弱体やボス自身の強化は消さない
- 攻撃技はどれも「両方」(攻撃と魔攻の平均)で、相性が乗る。効果は今ある仕組み(1回休み・やけど・まひ・能力の上げ下げ・回復)だけを使う
- 4階層目から敵が強くなるので、実装後に敵の攻撃の倍率をテストで合わせ直す
- 修行バトルのボスは、自分の属性の①〜③+必殺技
