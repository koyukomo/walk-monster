# コロッセオの仕様(2026-11-03 ユーザー確定)

## 入り方
- ホームから入る(ボタンは最小限)。受付はルミナドラ(sprites.js の light9)。ジム・ショップと同じ作り:受付で話しかけ →「挑戦する/やめる」→ クラス → ランク → 確認
- 受付の絵:colart.js の window.COLART.front(360×331)
- クラスを選ぶ画面のキャラの小さな絵は、縦横比を保って枠に収める(幼体クラスのポワリが縦に伸びていた)
- 挑戦には「コロッセオの招待状」1枚を使う(1日1回の制限はなし)
- BGM(コロッセオ専用、3つ):
  - 静かな曲:受付・トーナメント表・「はじめ!」まで。やや静かで、遠くに歓声が聞こえる感じ
  - 盛り上がる曲:バトル中。太鼓と金管のファンファーレ風、普通のバトルより速く、守護者戦とは別の明るく派手な曲
  - 歓声:決着がついたとき(「勝負あり!」から)。大きな歓声と短いファンファーレ

## クラスとランク
- クラス:幼体/成長体/成熟体/完全体/究極体。選べるのは**自分の今の段階のクラスと、1つ上のクラスだけ**(下のクラスは選べない。たまごは不可。究極体は究極体クラスだけ)
- ランク:下級・中級・上級。最初は下級だけ。下級を3連勝で中級、中級を3連勝で上級が開く(クラスごと)。S に記録
- 敵の強さの基準(育て方で決める):
  | ランク | 育て方 |
  | --- | --- |
  | 下級(あまり育てない子) | 1日3,000歩、スタミナは半分だけ使う |
  | 中級(ふつうの子) | 1日7,000歩、スタミナを全部使う(今の基準) |
  | 上級(かなり育てる子) | 1日12,000歩、スタミナを全部+ジムの今日のスペシャルも毎日 |
  - tests/balance.js の --grow を3つの育て方で回し、段階ごとの能力の平均を表(定数)にして、敵の能力にする
  - 3連戦の中でも少しずつ強く:1戦目0.9倍・2戦目1.0倍・3戦目1.15倍
  - 敵の攻撃は、ダンジョンと同じく「こちらの最大HPを1回で何%削るか」の考え方で、強すぎないよう合わせる

## トーナメントの流れ(8体のトーナメント=1回戦・準決勝・決勝の3連戦)
1. 受付完了:ルミナドラ「それじゃあ頑張ってね!」
2. トーナメント表(8体。自分と7体の名前と小さな絵):線がなぞられて、2体の線がぶつかる。自分以外の組も同時に線が進む
3. バトル画面に移る:「1回戦の相手は ○○選手です!」(2戦目は準決勝、3戦目は決勝)
4. 「はじめ!!」(ここまで静かな曲)
5. バトル(盛り上がる曲)
6. 決着:「勝負あり! 勝者は ○○選手です!」(歓声)
7. トーナメント表:勝った線が1段進む(ほかの組の勝者も決まる。ほかの組は自動で決める)
8. 受付に戻る:ルミナドラがひとこと → 「次へ進む/棄権する」。ここで HP・MP を15%回復。棄権したらそれまでに勝った分のコインをもらって終わり
- 負けたとき:6で「勝者は(相手)選手です!」→ 表で自分の線が止まる → 受付でひとこと → 終わり
- 決勝のあと:表で優勝の線が一番上まで進み、トロフィー → 受付でごほうび
- 歴代の子が出るときは、決勝の相手になる(表の決勝の山に、名前と世代で出る)

## 3連戦
- 敵は、そのクラスの段階の105体からランダム(隠し進化は出さない)。名前とタイプはキャラの設定、技はタイプと属性から
- HP・MPは持ち越し。戦いの間に、HPとMPを最大の15%回復
- アイテムは使える(持ち物から減る)。にげるは不可
- 能力の成長はなし(腕試しとごほうびの場所)
- バトル画面:ボス戦と同じ一人称。敵の絵の大きさもボス戦と同じ決め方(段階に合わせ、拡大は整数倍、縦横比はそのまま)。背景は闘技場(colart.js の COLART.bg、360×644。楽園の背景と同じように画面いっぱいに出す)

## 歴代の子
- 約20%で3戦目に出る。その子が最後になった段階と同じクラスにだけ出る(ランクは問わない)
- 亡くなったときの能力そのまま(S.hist)。「3代目 カゼムサ」のように名前と世代を出す
- 登場のカットインとセリフ1行(守護者ほど大げさにしない)

## ごほうび
| 結果 | ごほうび |
| --- | --- |
| 1勝ごと | コイン(クラスが上・ランクが上ほど多い。目安:成長体の中級で1勝30、究極体の上級で1勝150) |
| 3連勝 | 古代の回復薬か古代の魔導石のどちらか1つ+ガチャコイン1枚。クラス×ランクの初優勝でトロフィー(全15個) |
| 歴代の子に勝つ | 進化のカギ+思い出のメダル(その子の歴代の記録に印) |
| 負け | それまでに勝った分のコインはもらえる。招待状は戻らない |

- ガチャコイン:新しい「だいじなもの」。ガチャを作るまで、たまるだけ
- トロフィーと思い出のメダルは、受付の画面か歴代の記録で見られるようにする
