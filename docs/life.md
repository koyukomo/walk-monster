# キャラとの生活(なつき度)の仕様

「歩く→攻略」とは別の軸で、自分のキャラとの毎日を楽しむための仕組み。
作る順番:1. なつき度+なでる・ごはん・おねだり → 2. 進化の道を2本にしてなつき度とつなげる → 3. ひとこと・会話 → 4. おもちゃ・模様替え → 5. 日記・アルバム

## なつき度
- 0〜100。ホームの左上に「なつき ♥♥♥♡♡」(20ごとにハート1つ、5段階)。ステータスの「せわ」タブにも数字で出す
- その子だけのもの。たまごから育て直すと0から
- 上がる:なでる +1(1日10回まで)/おねだりをかなえる +5/ごはん +1/好物のごはん +3
- 下がる:育成ミス -5(0より下にはならない)

## なでる
- ホームのキャラを指でなでる(左右に動かす)とハートが出て喜ぶ
- 寝ているときは嫌がる(💢が出て、なつき度は上がらない)
- 指を左右に動かして向きが2回かわる(合計90px以上)と1回なでたことになる

## おねだり
- 起きている時間に、1日3回まで、ランダムで出る(30秒ごとに0.6%=平均で約1時間半に1回)
- キャラの頭の上に大きめの吹き出し(お知らせの吹き出しとは別。キャラといっしょに動く)
- 種類:「なでて〜!」/「〇〇がたべたい!」(お肉か、持っている食べ物。おなかが空いているときだけ・半々)
- かなえると +5。しばらく(ゲームの時間で約2時間)かなえないと、吹き出しは消える(罰はなし)

## ごはん
- ごはんボタンで、下にお皿の棚が出る。食べ物を指でつかんでキャラの口まで運ぶと食べる
- 左はしは「おにく」(無料・いくつでも。能力は上がらない)。その右に、持っている食べ物を個数つきで並べる(横にスクロール)
- 今までどおり、おなかのハートが減っているときだけ食べられる(1日3〜4回)
- 好物と苦手:キャラごとに、おにく+食べ物10種類から好物1つ・苦手1つ。最初は「?」で、食べさせると分かる(★好物/ふつう/苦手)
  - 表は index.html の FDF(キャラらしく決めた)。分かったことは S.fdk に残り、寿命でも消えない
  - 好物:大喜び、なつき度+3、上がる能力が1.5倍(四捨五入。攻撃+5・HP+23・MP+9)
  - 苦手:そっぽを向いてから食べる。なつき度は上がらない(能力は上がる)

### 食べ物10種類(1つ食べると決まった能力が上がる)
上がる量はジム1回の約半分(割合はジムと同じ):攻撃・防御・素早さ・魔攻・魔防 +3、HP +15、MP +6

|---|---|---|
| ほのおトマト | 攻撃 | ショップ・宝箱 |
| ゴツゴツいも | 防御 | ショップ・宝箱 |
| かぜのみ | 素早さ | ショップ・宝箱 |
| まほうキノコ | 魔攻 | ショップ・宝箱 |
| ひかりミルク | 魔防 | ショップ・宝箱 |
| げんきバナナ | HP | ショップ・宝箱 |
| ほしぶどう | MP | ショップ・宝箱 |
| ドラゴンステーキ | 攻撃・魔攻 | 宝箱だけ(めずらしい) |

- ショップの値段は1つ50コイン。持ち物と同じく種類ごとに9個まで。寿命でも失わない。売値は25コイン(宝箱だけの3つは売れない)
- 宝箱(ふつう・豪華)の中身が回復アイテムのとき、25%で食べ物になる。重み:ショップの7種類 各13%・ステーキ/パイ 各4%・ゼリー 1%
- 持ち物の「たべもの」タブで見られる(使うのはホームのごはんから)

## 進化の道となつき度
- 完全体まで、どのキャラも行き先が2つ。片方は今までどおり「能力の偏り」、もう片方は「なつき度が高い」と進める「なつきの道」
- 能力の条件となつきの条件を両方満たしたら、進化のときに2体の影から自分で選べる(今のインセクトの道の選び方と同じ)
- なつき度が低くても進化はできる(罰にはしない)
- 完全体→究極体と隠し進化は今のまま
- 1本道だった9か所に追加する行き先(どれもなつきの道):
  ヒガネジシ→カマドロイド/ヤゴット→シオドラ/ペラット→カザドラ/ビリテン→ゴロドラ/ハニポ→ツチドラ/ホタポ→ヒカドラ/ツキミミ→カンテロイド/インプン→ヨルドラ/ヨルドラ→ガーゴロイド
- もともと2本ある所も、どちらをなつきの道にするかを表で決める(未決定)
