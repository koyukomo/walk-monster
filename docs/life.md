# キャラとの生活(なつき度)の仕様

「歩く→攻略」とは別の軸で、自分のキャラとの毎日を楽しむための仕組み。
作る順番:1. なつき度+なでる・ごはん・おねだり → 2. 進化の道を2本にしてなつき度とつなげる → 3. ひとこと・会話 → 4. おもちゃ・模様替え → 5. 日記・アルバム

## なつき度
- 0〜100。ホームの左上に「なつき ♥♥♥♡♡」(20ごとにハート1つ、5段階)。ステータスの「せわ」タブにも数字で出す
- その子だけのもの。たまごから育て直すと0から
- 上がる:なでる +1(1日10回まで)/おねだりをかなえる +5/ごはん +1/好物のごはん +3
- 下がる:育成ミス -5(0より下にはならない)

## なでる
- ホームのキャラを指でなでる(左右に動かす)とハートが出て喜ぶ
- 寝ているときは嫌がる(💢が出て、なつき度は上がらない)
- 指を左右に動かして向きが2回かわる(合計90px以上)と1回なでたことになる

## おねだり
- 起きている時間に、1日3回まで、ランダムで出る(30秒ごとに0.6%=平均で約1時間半に1回)
- キャラの頭の上に大きめの吹き出し(お知らせの吹き出しとは別。キャラといっしょに動く)
- 種類:「なでて〜!」/「〇〇がたべたい!」(お肉か、持っている食べ物。おなかが空いているときだけ・半々)
- かなえると +5。しばらく(ゲームの時間で約2時間)かなえないと、吹き出しは消える(罰はなし)

## ごはん
- ごはんボタンで、下にお皿の棚が出る。食べ物を指でつかんでキャラの口まで運ぶと食べる
- 左はしは「おにく」(無料・いくつでも。能力は上がらない)。その右に、持っている食べ物を個数つきで並べる(横にスクロール)
- 今までどおり、おなかのハートが減っているときだけ食べられる(1日3〜4回)
- 好物と苦手:キャラごとに、おにく+食べ物10種類から好物1つ・苦手1つ。最初は「?」で、食べさせると分かる(★好物/ふつう/苦手)
  - 表は index.html の FDF(キャラらしく決めた)。分かったことは S.fdk に残り、寿命でも消えない
  - 好物:大喜び、なつき度+3、上がる能力が1.5倍(四捨五入。攻撃+5・HP+23・MP+9)
  - 苦手:そっぽを向いてから食べる。なつき度は上がらない(能力は上がる)

### 食べ物10種類(1つ食べると決まった能力が上がる)
上がる量はジム1回の約半分(割合はジムと同じ):攻撃・防御・素早さ・魔攻・魔防 +3、HP +15、MP +6

|---|---|---|
| ほのおトマト | 攻撃 | ショップ・宝箱 |
| ゴツゴツいも | 防御 | ショップ・宝箱 |
| かぜのみ | 素早さ | ショップ・宝箱 |
| まほうキノコ | 魔攻 | ショップ・宝箱 |
| ひかりミルク | 魔防 | ショップ・宝箱 |
| げんきバナナ | HP | ショップ・宝箱 |
| ほしぶどう | MP | ショップ・宝箱 |
| ドラゴンステーキ | 攻撃・魔攻 | 宝箱だけ(めずらしい) |

- 持ち物の「たべもの」タブで見られる(使うのはホームのごはんから)

## 進化の道となつき度
- 完全体まで、どのキャラも行き先が2つ。完全体→究極体も、完全体ごとに行き先の組み合わせがちがう(隠し進化は別で今のまま)
- 進化先の候補ごとに「能力の条件」を表で持たせる(index.html の EVC。キャラの見た目・タイプに合わせた)
  - 能力の条件の数:成長体2つ/成熟体3つ/完全体4つ/究極体5つ
  - 条件の種類:「攻撃 135 以上」(数値は段階ごとの目安 EVB。「高い」条件はその1.25倍)/「攻撃が一番高い」/「素早さが防御より高い」/「毎日 6,000歩 以上 歩く」(今の段階の1日の平均。前のインセクトの道の条件)
  - 同じ進化元の2つの候補は、条件がちがう
- なつき度の条件は、2つの候補のうち片方だけ(なつきの道。index.html の EVN)。成長体へ♥2・成熟体へ♥3・完全体へ♥4 以上。足した9本は全部なつきの道
- 当てはまる数(なつきの道は なつき度も1つ)が一番多い候補に進化。同じ数なら、進化のときに2体(3体)の影から自分で選ぶ
- 究極体:なつき♥4以上は必ず必要+能力の条件5つのうち4つ以上で進化。当てはまる候補が2つ以上なら、数が多い方(同じなら選ぶ)。足りなければ今までどおり寿命
- ステータスの「しんか」:進化図の最有力(オレンジの点滅)=当てはまる数が一番多い候補。候補を押すと条件の一覧が出て、当てはまるものに✓・「〇/3 当てはまり」
- 数値の合わせ方:`node tests/balance.js --evo --runs 30`(遊び方をばらつかせて育てた子:1日 3,000〜10,000歩・ジムと修行バトルの割合・ジムで選ぶ能力・なつき度 1日0〜25 をランダム)で、どの候補にも30〜70%くらいずつ進化するように合わせた。結果は tests/output/balance-evo.md
- balance.js の --grow・--gen の子は、なつき度が1日12上がる(なでる10回+ごはん2回)
- 1本道だった9か所に追加した行き先(どれもなつきの道):
  ヒガネジシ→カマドロイド/ヤゴット→シオドラ/ペラット→カザドラ/ビリテン→ゴロドラ/ハニポ→ツチドラ/ホタポ→ヒカドラ/ツキミミ→カンテロイド/インプン→ヨルドラ/ヨルドラ→ガーゴロイド
- 完全体→究極体(各属性の4体を「2体ずつの3通り+3体全部」に)
  - 火:ブレイズドラゴ→インフェルドラゴン/ヴォルカノイド、バクエンガ→ソルガオウ/インフェルドラゴン、オニビカブト→ヴォルカノイド/ソルガオウ、カマドロイド→3体
  - 水:オルガロウ→ワダツオウ/リヴァイドラ、タイダルドラ→リヴァイドラ/ディープスコル、タガイクサ→ディープスコル/ワダツオウ、ディープロイド→3体
  - 風:カゼグリフ→ハヤテオウ/テンペスドラゴ、ゲイルドラ→テンペスドラゴ/フウジンギア、カゼキリ→ハヤテオウ/フウジンギア、エアロイド→3体
  - 雷:ウンライドラ→ケラウノドラゴ/ライジンオウ、ライゴウ→ライジンオウ/ライオウガタ、ナルカミキリ→ライオウガタ/ケラウノドラゴ、ボルタンク→3体
  - 土:ガンザンコウ→サジンジゴク/ドグウジン、ゴロバサミ→サジンジゴク/タイザンドラゴ、グランドラ→タイザンドラゴ/ドグウジン、ホリロイド→3体
  - 光:コウリン→テンリン/ヒジリアゲハ、アゲハリオ→ヒジリアゲハ/アマツドラゴ、ルミナドラ→アマツドラゴ/テンリン、カンテロイド→3体
  - 闇:デモドラ→マオウドラゴ/マカイキシン、ゴクケン→マオウドラゴ/ベルゼオウ、ジゴクバエ→ベルゼオウ/マカイキシン、ガーゴロイド→3体

## ひとこと・会話
- ホームでキャラをタップすると、頭の上の吹き出し(おねだりと同じ形)でしゃべる。なでるのとは別
- ひとりごと:タップしなくても、起きている間はゲームの時間で1時間に1回くらい。寝ているときは寝言(「すやすや…」「むにゃ…トマト…」)
- 話し方:幼体=鳴き声だけ(ぴぃ!・きゅ〜・むにゃ…)/成長体=カタコト(おなか、すいた)/成熟体から=ふつう+タイプの口ぐせ
  - ドラゴン=勝ち気、ビースト=元気、ゴースト=いたずら好き、インセクト=のんびり、ロボ=機械っぽい(ピピッ、〜デス)
- 内容:時間帯(朝・昼・夜)/最近のできごと(到達階層・倒した守護者・今日の歩数・ジム・好物・ガチャ)/お世話(おなか・うんち・育成ミスのあと)/なつき度で増えるセリフ(♥1〜2 よそよそしい→♥5「ずっといっしょにいようね」)/特別な日(進化した日・誕生日・寿命が近い日「…いままで、ありがとう」)
- 同じセリフが続かないようにする
- 作り(index.html):
  - タップ=ほとんど動かさずに(10px未満・0.6秒以内)離す。左右に動かすと、なでる
  - ひとりごと:ホームを見ているとき、30秒ごとに 1/120(ゲームの時間で約1時間に1回)。おねだりが出ているときは出さない。しゃべっている間(約4秒)はおねだりの吹き出しをかくし、キャラは止まる
  - 話す種類の重み:特別な日4(寿命が近い日は5)・お世話3・できごと2・なつき度2・時間帯2。寝ているときは寝言だけ
  - 時間帯:朝5〜10時・昼10〜17時・夜17〜5時
  - 最近のできごと:S.lg(その子だけ・寿命で消える)に、階層の突破・守護者・ジム・好物を食べた・ガチャのカード・育成ミスを記録。2日以内のものと、今日の歩数(3,000歩以上)を話す
  - 特別な日:進化した日/誕生日(5の倍数の歳の日)/寿命が近い日(究極体は寿命まで1日未満、完全体は究極体になれずに15才まで1日未満)
  - なつき度:♥0〜1 よそよそしい/♥2〜3/♥4/♥5 は「ずっと いっしょに いようね」も
  - 幼体は鳴き声だけ(タイプ別・元気/しょんぼり/寝言)、成長体はカタコト(全タイプ共通)、成熟体からはタイプ別の口ぐせ
