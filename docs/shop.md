# ショップとコインの仕様(2026-11-03 ユーザー確定)

## 場所と店員
- ショップは楽園とホームの両方で使える(ホームは今のボタンを最小限で足す。画面の作り直しのときに整理する)
- 店員はカゼキリ(sprites.js の wind9)
- 流れ(トレーニングジムと同じ作り):ショップを開く → カゼキリが受付で話しかける → 「買う/売る/やめる」の3択
  - 買う:売る物の一覧 → 個数を選んで買う → ひとこと
  - 売る:持ち物の一覧(売れる物だけ)→ 個数を選んで売る → ひとこと
  - やめる:ひとことで閉じる(楽園・ホームに戻る)
- 買う・売るたびに「チャリン!」の効果音
- ショップの中は、ホームから開いたときも楽園のBGMを流す

## お金
- 名前:コイン(🪙)。S にコインの数を保存
- 寿命・気絶・ひきかえすでも失わない(アイテムと同じ)

## コインの手に入れ方
| 手に入れ方 | コイン |
| --- | --- |
| ふつうの敵(ダンジョン) | 5+階層÷2(切り捨て。1階層=5、50階層=30) |
| 宝箱 | コインかアイテムのどちらか1つ(半々)。コインなら20〜50、豪華な宝箱は2倍 |
| 普通のボス | 50+階層×5 |
| 守護者 | 階層×30(5階層=150〜50階層=1,500) |
| 歩数ボーナス | 1日1回、その日の歩数で:3,000歩=30/7,000歩=100/10,000歩=200(段階ごとに受け取れ、合計で最大200) |

- 目安:1日7,000歩で約200コイン(薬草6〜7個分)
- 修行バトルとジムではコインは出ない(ダンジョンと歩数だけ)
- リザルト画面に、もらったコインを出す

## 売る物
| アイテム | 効果 | 値段 | 買える数 |
| --- | --- | --- | --- |
| 薬草 | HP10%回復 | 30 | 持てる数まで(9個) |
| 回復薬 | HP20%回復 | 80 | 9個まで |
| 魔力の欠片 | MP10%回復 | 40 | 9個まで |
| 魔導石 | MP20%回復 | 100 | 9個まで |
| チップ7種 | その戦闘だけ能力+20% | 各60 | 9個まで |
| コロッセオの招待状 | コロッセオ1回 | 300 | 1日1枚 |
| 導きの石(新) | 下を参照 | 150 | 1日1個 |
| 今日の掘り出し物 | 古代の回復薬・古代の魔導石のどちらか(日替わり) | 250 | 1日1個 |

- 売らない:古代の回復薬・古代の魔導石(掘り出し物だけ)、スタミナのたね(バランスが崩れるため)、進化のカギ(レアから)
- 持ちきれないアイテム(9個を超えた分)は、今と同じく手に入らない(「持ちきれない…」)。自動でコインにはしない

## 売る
- 売値は、ショップの値段の半分(切り捨て)
- 古代の回復薬・古代の魔導石は 125(掘り出し物の値段の半分)
- 売れない物:進化のカギ・宝玉・石板などのだいじなもの、スタミナのたね(持たずに使うので)
- 招待状と導きの石は売れる(150・75)
- ガチャのダブったカードも売れる(一覧の下の「カード」の区切り。2枚以上あるカードだけ、最後の1枚は残す。売値は docs/gacha.md の「ダブり」)
- いらないチップや、持ちきれなくなりそうな回復アイテムを、自分で選んでコインにする
- 「1日」はゲームの日付(ほかの1日1回と同じ数え方)

## 導きの石(みちびきのいし)・新しいアイテム
- ダンジョンを歩いている途中に使う(バトル中・たき火のあとは使えない)。今いる場所に目印を置く
- そのあと「ひきかえす」や気絶をしたら、次は目印の場所から再開する
  - HP:ひきかえすはそのまま、気絶は全回復(今のルールと同じ)
  - ボス戦の気絶は、今と同じくたき火から(目印より先なので)
- 目印が消えるとき:目印から1回再開したとき/その階層をクリアしたとき/寿命
- 目印は1つだけ。置き直すと前の目印は消える(石は1個減る)
- 未確定の進化のカギは守れない(気絶で失うのは今と同じ)
- 手に入れ方:ショップ(150コイン・1日1個)、宝箱からもたまに出る(回復アイテムと同じくらいの出やすさより少なめ)
- 種類ごとに9個まで(ほかのアイテムと同じ)。持ち物の画面に絵と説明を出す
